Amazon $3,
What It Is

‘Amazon Simple Storage Service (Amazon $3) is an object storage service offering industry-
leading scalability, data availability, security, and performance.
Store and retrieve any amount of data from anywhere on the web.

Core Concepts
+ Buckets:
© Top-level container for objects.
© Globally unique name.
o Defined in a single AWS Region.
+ Objects:
o Data stored in buckets.
© Consists of key (name), value (data), metadata, and version ID.
© Keys:
o Unique identifier for an object within a bucket.
+ Regions:
o Buckets are created in a specific AWS Region.
